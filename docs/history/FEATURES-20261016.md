# 新功能与操作说明（2026-10-16）

## 截图工具

右侧「截图并保存」或截图页「截图并自动保存」在后台获取仪器屏幕；默认保存到 `data/screenshots/`，命名为 `ZDS_年月日_时分秒_微秒.png`，避免覆盖。可选择 PNG/BMP、保存目录和自定义前缀；每次截图保存这些选项。

- 「图片反色」：改变预览、复制、查看及另存为效果。勾选后再截图，自动保存原图和带 `_inverted` 标记的反色图；原图字节保持不变。截图后才勾选反色，可点击另存为保存该效果。
- 「保存至剪贴板」：勾选时，成功截图后自动复制原尺寸图片，可粘贴至聊天、Word 或画图；未勾选时保留现有剪贴板内容。
- 「复制图片」：手动复制当前原色/反色效果，不复制缩小后的预览。
- 「查看图片」或双击预览图：新窗口以 100% 原尺寸显示，可滚动；主界面图片始终缩放在预览区域内，不扩大截图面板，不挤压上方波形。
- 「另存为」及「打开目录」：选择保存位置或直接查看已保存文件。

截图通信或解码失败不会提示成功；保存失败时保留已接收图片供另存为，上一张有效图片也不会被失败响应替换。实时流请先关闭再截图。真机已验证 PNG 800×480、29120 字节，接收并自动保存约 0.7 秒；BMP 同为 800×480、1152054 字节，约 0.4 秒（单次实测，不代表固定速度）。含截图的新回归测试共 58 项通过。

运行 `python run_app.py --screenshots` 可直接打开截图页。

## 连接后以示波器设置为准

连接、同步、RUN/STOP/SINGLE 和波形读取在后台执行。连接后只查询仪器配置，不发送初始化设置。在仪器面板修改后，点击「同步当前设置」。每次编辑只写所选参数并读回。

「触发、采集与完整通道设置」页显示实际 SCPI 返回值，可明确编辑：

- 触发类型、触发源、方式、耦合、释抑；按当前触发类型查询对应参数。触发状态只读。
- 采集模式、平均次数、存储区域；实际存储深度/采样率在右侧显示。
- CH1–CH4 的单位/探头类型、倍率、输入阻抗、反相、延迟校正。

触发源即使来自未显示通道也保留。CH2 触发不要求开启 CH2 波形显示。只同步不强制切换任何触发源。SINGLE 后等待触发是正常状态，不等于断线。

## 保存完整数据

「SCREen」只读屏幕记录，「MEMOry」读存储记录。界面概览抽样，原始 WFM 不抽样。MEMOry 读取后保存到 `data/reads/`。

「文件 → 导出完整测试快照包」保存到 `data/captures/`。下载前停止采集并确认 Stop；原先为 Run 时，结束后恢复 Run；原先为 Single 时保持停止，避免重新触发。不会为下载发送 SINGLE。可勾选等待当前触发完成，超时则报错，不切换触发源。

默认保存紧凑 WFM 和元数据。全量 CSV、NPZ、ZIP 按需勾选；大记录 CSV 可达数十 GB，导出明显慢于原始数据传输。

| 文件 | 内容 |
| --- | --- |
| waveform.wfm | 仪器实际返回的完整原始字节 |
| metadata.json / settings_snapshot.json | 头字段、通道字段、仪器设置、点数、数据来源、换算说明 |
| measurements.json | 有效硬件测量；无效/超量程为 null，元数据另存原响应 |
| test_context.json | 电路、工况、通道含义、探头、阈值和备注 |
| integrity_report.md / RECORD_README.md | 完整性检查、已知限制、记录说明 |
| analysis_events.json（可选） | 完整记录扫描及候选异常位置 |
| CSV（可选） | 全部返回点的索引、时间、派生物理量和原始码 |
| waveform_full.npz（可选） | 分块生成完整数组；电流字段 current_a，电压 voltage_v |
| screen.png（可选） | 仪器原生截图 |

已确认容量：仅 CH1+CH3、CH2+CH4 为 512M；CH1+CH2、四通道、CH2+CH3+CH4、CH3+CH4 为 256M。其他组合待确认。容量提示不自动设置深度，完整性依据实际查询、头字段、返回点数及传输字节判断。

## 区间、异常与工程

在「测试工况、区间导出与异常定位」页填写工况和各通道信息。

1. 输入起止时间并选通道，导出区间 CSV。保留每个点的原始索引、时间、原始码；完整记录不被覆盖。
2. 完整记录扫描分块处理，可取消。检查疑似码值削顶、孤立尖峰、上下限超出，以及根据预期频率或局部周期估计的缺脉冲/周期异常。统计覆盖全部点，候选列表每通道最多 200 项；候选不是已确认故障。
3. 点击候选事件定位原始采样附近；「全屏自适应」恢复全记录概览。
4. 保存离线工程，包含 WFM、设置、工况、光标、选区、分析报告和 SHA256。打开时先校验，不向连接的仪器写设置。

FFT 取起始最多 200000 个连续点，摘要明确注明窗口。概览曲线、摘要文本不能代替完整记录。

## 离线任务与设备操作

导出结束后由主线程恢复任务状态，并以定时检查兜底；离线导出不锁定设备控制。全量 CSV 导出显示进度且允许取消。取消后保留部分文件，不覆盖已有导出文件，原始记录保持完整。
